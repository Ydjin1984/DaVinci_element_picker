# DaVinchi brand

## Naming

| Role | Value |
|------|--------|
| **Product** | DaVinchi |
| **Repo** | `davinci-element-picker` |
| **Package id** | `coin-rebalancer.element-picker` (extension) |
| **Tagline (EN)** | Pick the element. Feed the agent. |
| **Tagline (RU)** | Выбери элемент — отдай агенту. |
| **One-liner** | Element Picker for VS Code & Cursor — screenshot + HTML/CSS for AI agents. |

### Why “DaVinchi”?

Play on **Da Vinci** (observation, proportion, craft) + **vinci / win** energy — without claiming the historical name as a trademark story. Spelling is intentional: **DaVinchi** (capital V, chi ending).

## Visual system

| Token | Hex | Use |
|-------|-----|-----|
| Void | `#0b0e14` | Backgrounds |
| Cyan | `#4fc3f7` | Accent / highlight / mark |
| Blue | `#4f8cff` | Secondary accent |
| Text | `#dce3f0` | Primary text on dark |
| Muted | `#7686a3` | Secondary text |

**Mark:** diamond + reticle + pick core (precision × selection).  
**Activity Bar:** monochrome `#c5c5c5` SVG (`media/icon.svg`) — host recolors.  
**Marketplace / social:** `media/icon.png`, `docs/media/hero.jpg`, `docs/media/og-card.jpg`, `docs/media/brand-board.jpg`.

## Voice

- Short, technical, agent-first.
- No “revolutionary AI” fluff.
- Prefer “agent” over “Copilot” unless comparing.
